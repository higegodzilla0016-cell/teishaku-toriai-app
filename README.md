# 定尺・4×8板取り合い計算アプリ step2

復旧後に安全に追加するための step2 です。

## 追加内容

- 既存の定尺計算
- 4×8板材タブ
- シャーリングver / レーザー切断ver の切替
- シャーリングverは回転なし・帯取り優先
- シャーリング順を簡易表示
- レーザー切断verは矩形ネスティング優先

## まだ未追加

- 印刷専用レイアウト修正
- 手前残材が短すぎる場合の詳細判定
- 縞目方向の矢印表示

## 4×8入力例

```text
1664x352x3
1064x552x3
1064x584x2
800x400x4
500x300x6
```

形式：幅x長さx枚数
