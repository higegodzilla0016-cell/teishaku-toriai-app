# 定尺・4×8板取り合い計算アプリ step3

安全追加の step3 です。

## 追加内容

- 既存の定尺計算
- 4×8板材タブ
- シャーリングver / レーザー切断ver の切替
- 印刷時に4×8母材1枚を1ページに収める安全レイアウト

## 印刷設定

- 用紙：A4
- 向き：横
- 余白：最小
- 倍率：100%
- 背景のグラフィック：ON

## 注意

この版では「必ず1ページに収める」ことを優先して、4×8図は縦長で中央配置にしています。


## Step3.1 印刷修正

印刷時に下部の寸法一覧・シャーリング順が次ページへ押し出される問題を防ぐため、印刷時は母材図のみを表示するようにしています。


## Step3.2 A4横向き印刷

印刷時だけ4×8母材を90度回転して、A4横ページに合わせて横向き表示します。
画面表示は従来通りです。


## Step3.3 スマホ表示修正

スマホ画面で4×8母材図が横にはみ出ないよう、画面表示のみ横幅100%で自動縮小する方式に変更しています。
印刷用レイアウトは維持しています。


## Step4 取り合い改善

- レーザーverは複数の並び順でネスティングして、一番良い結果を採用
- シャーリングverは帯方向を「自動 / 横帯 / 縦帯」から選択可能
- シャーリングverの自動では、横帯と縦帯を比較して良い方を採用
- 1664×352のような長い部材も、4×8長手方向へ合わせて入る向きを判定


## Step5 シャーリング端材詰め改善

- シャーリングverで、母材を増やす前に既存母材の空きスペースを再確認
- 500×300などの小物を前の母材の端材スペースへ寄せる候補を比較
- 母材枚数または端材が改善する場合は「端材詰め改善」を自動採用
- レーザーver、スマホ表示、印刷表示は維持


## Step6 端材詰め強化

- MaxRects方式で既存母材の空き矩形を全確認
- 新しい母材を作る前に、全母材の空きへ小物を試し入れ
- シャーリングverの自動では、帯取り候補と端材詰め候補を比較
- レーザーverもMaxRectsで詰めを改善


## Step7 現場実用機能追加

- 母材ごとの重量表示
- 母材図に簡易寸法線を追加
- 案件名付きで入力データ保存・呼び出し
- シャーリング順を実機向けの帯取り指示に改善


## Step8 定尺計算にもStep7機能を反映

- 定尺計算に案件名付き保存・呼び出しを追加
- kg/m入力による重量計算を追加
- 定尺1本ごとの元材重量・部材重量・端材重量を表示
- 切断指示を現場向けに整理
- 40x40x4Lなどは概算kg/mを自動計算


## Step9 空欄開始版

- URLを開いた時、過去の入力寸法が自動表示されないように変更
- 定尺寸法入力、端材入力、4×8板材寸法入力は空欄で開始
- 案件保存したデータは「保存案件を呼び出し」から呼び出し可能
- 「保存データを全削除」ボタンを追加
- 入力例はボタンで手動挿入可能


## Step10 初期材料リスト追加

初期材料として、よく使うアングル材・FB材を登録済みにしました。

### 初期登録材料例

- 30x30x3L
- 40x40x3L
- 40x40x4L
- 50x50x4L
- 50x50x6L
- 65x65x6L
- 75x75x6L
- FB 32x4
- FB 38x6
- FB 50x6
- FB 65x6
- FB 75x6
- FB 100x6
- 6m材の一部

材料登録タブに「初期材料にリセット」を追加しています。


## Step11 SS400規格寸法ベース

初期材料をSS400の規格・一般流通標準寸法ベースに整理しました。

### 主な変更

- 40x40x4Lは初期材料から削除
- 40x40x3L、40x40x5Lを採用
- 等辺山形鋼L材は標準寸法とkg/mを登録
- FBはSS400平鋼の一般流通標準寸法ベースで登録
- 材料登録タブの「初期材料にリセット」でこのリストに戻せます


## Step12 初期材料自動リセット

- アプリ起動時に材料プリセットのバージョンを確認
- 古い材料リストがブラウザ内に残っていても、SS400規格材料リストへ自動更新
- 案件保存データは削除しない
- 材料登録タブの「初期材料にリセット」でも同じSS400規格材料へ戻せる


## Step13 材料カテゴリー分け

材料登録タブを以下のカテゴリーに分けました。

- SS400 山形鋼
- SS400 FB
- その他

定尺計算タブの材料選択もカテゴリー別に表示されます。
材料プリセットバージョンを更新しているため、起動時にSS400カテゴリー済み材料へ自動更新されます。


## Step14 定尺重量表示の整理

定尺計算側の重量表示を以下に整理しました。

- kg/m
- 定尺1本重量
- 必要本数
- 定尺必要本数の総重量
- 使用部、つまり部材のみの重量
- 端材重量目安

定尺1本ごとの表示も「定尺1本重量・使用部重量・残り重量」に整理しています。


## Step15 左側入力欄にも重量表示

定尺計算の入力欄側にも以下を表示するようにしました。

- 定尺1本重量
- 必要本数
- 定尺総重量
- 使用部重量

部材寸法を入力すると、左側でもすぐ重量確認できます。
