# 定尺・4×8板取り合い計算アプリ

定尺材と4×8板材の取り合い計算ができるWebアプリです。

## 追加済み機能

- シャーリングver / レーザー切断ver の選択
- シャーリングver：帯取り優先、シャーリング順表示、縞目固定、手前残材警告
- レーザー切断ver：矩形ネスティング優先、回転あり/なし
- 4×8を複数枚まとめてA4横PDF/印刷
- 母材枚数、歩留まり、重量目安

## 入力例

```text
1664x352x3
1064x552x3
1064x584x2
800x400x4
500x300x6
```

形式：幅x長さx枚数


## 印刷修正

4×8板取り図がA4横に収まるよう、印刷専用CSSを追加しています。


## 印刷修正：母材1枚/1ページ

4×8板取り図はA4横で母材1枚を1ページに出す設定にしています。


## 印刷修正：A4横いっぱい表示

印刷時は4×8板を横向きに変換して、A4横いっぱいに母材1枚を1ページで表示します。
